CHRONO-ASTROLABE // 創世の天体儀

INTERACTIVE AUDIO-VISUAL SYSTEM & TERMINAL MANUAL

01 // STARTUP & CAMERA（基本操作）

  • 画面クリック：重低音ドローン・電子音響・システム音声を起動し、空間の中心から衝撃波を発生させます。
  • ドラッグ / ホイール：3D空間を360度自由に回転・ズームして鑑賞できます。
  • 右上 [ + CTRL PANEL ]：BPM（テンポ）変更、ビート切替、作品画像のPNG保存が行えます。

02 // AESTHETIC MODES（3つの美学モード：キー 1 - 3）

※半角英数モードで数字キーを押すか、下のコマンドをクリックして切替できます。

03 // TERMINAL COMMANDS（文字入力 + ENTER / クリック実行）

キーボードから直接タイプして Enter を押すか、各コマンドをクリックして起動できます。

matrix3Dマトリックス・コードレイン
treeL-System電脳フラクタルツリー
terrainサイバーワイヤーフレーム山脈
flockボイド群れアルゴリズム切替
beat4つ打ちテクノドラム＆ベース
align黄金比フォーメーション一斉整列
zero無重力・時間停止（Zero-G）
pulse衝撃波パルス＆3音アルペジオ
glitch信号攪乱（デジタルグリッチ）
overdrive全機能フル覚醒モード（BPM175）
dissolveマニフェスト隠し音声詠唱
reset初期ギャラリー状態へリセット

04 // OPTICAL FILTERS & GRAVITY（Shift同時押し / コマンド）

Shift + G 長押し→離す：ブラックホール重力＆大爆発 Shift + S 作品PNG保存
